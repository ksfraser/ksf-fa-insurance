# ksf_fa_insurance

FrontAccounting **UI/hooks** for insurance planning. Part of the `ksf_insurance`
triple (`ksfraser/ksf_insurance` + `ksfraser/ksf-fa-insurance` + `ksfraser/ksf-wp-insurance`).

- Business logic lives in [`ksfraser/ksf_insurance`](https://github.com/ksfraser/ksf_insurance)
  (namespace `Ksfraser\Insurance`).
- Shared calculation framework lives in `ksfraser/ksf_modules_common`.
- This repo provides the FA module hooks and admin page that display insurance-needs,
  valuation, and comparison results for a client.
